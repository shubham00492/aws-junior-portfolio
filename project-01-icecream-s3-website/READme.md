# Project 01 - Ice Cream Shop Static Website on S3

## Goal
Host a static website for an ice cream shop using AWS S3.

## Services Used
- Amazon S3 (Static Website Hosting)
- S3 Bucket Policy (Public Read)

## Steps I Did
1. Created S3 bucket: `icecream-shop-website-shubham`
2. Enabled Static Website Hosting
3. Uploaded index.html, style.css
4. Set bucket policy for public access
5. Got website URL and tested

## S3 Bucket Policy Used
Public read for GetObject
