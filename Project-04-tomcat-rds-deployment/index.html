2-Tier Java Web App, deployed on AWS

A Java web application deployed on Apache Tomcat (EC2) with an AWS RDS MySQL backend, connected over an SSL-secured JDBC pool inside a configured VPC.

Application tierEC2 · Amazon Linux 2023 · Tomcat 9.0.117
Data tierRDS MySQL · db.t3.micro
ConnectivitySSL-secured JDBC via MySQL Connector
PreparedApril 2026

This project demonstrates deploying a two-tier web application on AWS: the application tier runs a Java WAR artifact on Apache Tomcat, and the data tier is a fully managed RDS MySQL instance. Below is the architecture, the full build process, real issues hit along the way, and what came out of it.
