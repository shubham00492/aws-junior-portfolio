Auto Scaling + Application Load Balancer

A self-healing, horizontally-scaling web tier on AWS: EC2 instances launched from a template, distributed across multiple Availability Zones, and load-balanced by an Application Load Balancer.

ComputeEC2 t3.micro · Amazon Linux 2023
ScalingASG · min 2 / desired 3 / max 5
Load balancingApplication Load Balancer · HTTP :80
AvailabilitySpread across 3 AZs

This project builds a highly-available web tier: a launch template bootstraps identical web servers automatically, an Auto Scaling Group keeps 2–5 of them running across multiple Availability Zones, and an Application Load Balancer spreads incoming traffic across whichever instances are healthy.

Proof it works

The real test of a load balancer: hit the same URL twice, get answers from two different servers.

GET http://auto-scaling-1-xxxxxxxx.us-east-1.elb.amazonaws.com
→ "Hello from ip-172-31-40-78.ec2.internal"
GET http://auto-scaling-1-xxxxxxxx.us-east-1.elb.amazonaws.com (refreshed)
→ "Hello from ip-172-31-2-93.ec2.internal"
Same URL, same request — two different internal IPs responded. That's the Application Load Balancer routing across healthy targets in the Auto Scaling Group, confirmed by refreshing the browser and watching the hostname change.
